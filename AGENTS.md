# go-browser-use

Unofficial Go client for the Browser Use Cloud API, generated from its public v4 OpenAPI document. For client usage, read [.agents/skills/go-browser-use/SKILL.md](.agents/skills/go-browser-use/SKILL.md). This file covers changes to the repository.

## Architecture

One generated package, `browseruse`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads `https://docs.browser-use.com/cloud/openapi/v4.json` to `api/openapi.json`. `scripts/patch-spec.sh` writes `api/openapi.fixed.json`, downconverting nullable unions, constants, and numeric exclusive bounds to OpenAPI 3.0.3. oapi-codegen reads `config.yaml` and generates `client.gen.go`.

## Stack

- Go 1.26.9.
- oapi-codegen v2.8.0, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: HTTP contract tests and the README example.
- `scripts/`: spec download and conversion, lint, and security scans.
- `api/`: downloaded and patched specs, gitignored.
- `vendor/`: dependencies, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The base URL includes `/api/v4`: `https://api.browser-use.com/api/v4`. Paths in the spec do not include this prefix.
- Set `X-Browser-Use-API-Key` in a request editor. The generated client does not install authentication automatically.
- Operation IDs contain resource and HTTP method suffixes, retained in generated method names.
- The OpenAPI 3.1 spec has `anyOf` null branches and numeric exclusive bounds. Conversion must preserve the non-null union branches and all operations.
- Number fields map to `float64`. Cost responses are decimal strings and remain strings.
- Optional pointer fields omit nil on serialization. Use a raw-body method when explicit JSON null is required to reset a setting.
- `InlineSecretSource.Value` is a pointer because the spec marks it write-only. Set it explicitly when constructing an inline binding.
- Event retrieval returns JSON, not a WebSocket connection. File upload endpoints return presigned URLs; uploading bytes is a separate request without the Browser Use API key.
- `make generate` fetches the current spec. Review the generated output after every regeneration.
- Security scanning handles source directories without Git history. No Git initialization is needed.
- Do not initialize Git, mutate Git or GitHub, publish, or call the provider API during this task.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
